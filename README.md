# Garden Wars: downloads

[Garden Wars](https://garden-wars.io) as a desktop app for Windows, macOS and Linux. It is the same game you can play in
your browser at [garden-wars.io](https://garden-wars.io), in its own window. It always plays the newest version of the
game, so you never reinstall for an update, and it plays the tutorial and the games against bots offline too.

| | Download | The first time you open it |
|---|---|---|
| **Windows** 10 and 11 | [Garden-Wars-windows-setup.exe](https://garden-wars.io/download/windows) | Windows may say "Windows protected your PC": click **More info**, then **Run anyway**. |
| **macOS**, Apple Silicon and Intel | [Garden-Wars-mac.dmg](https://garden-wars.io/download/mac) | Open it and drag Garden Wars into Applications. macOS says it can't check the app: open **System Settings → Privacy & Security**, scroll down and click **Open Anyway**. |
| **Linux**, x86-64 | [Garden-Wars-linux-x86_64.AppImage](https://garden-wars.io/download/linux) | Make it executable (`chmod +x Garden-Wars-linux-x86_64.AppImage`, or the file's Properties), then open it. |

Every version is on the [releases page](../../releases). Apple and Microsoft warn about the app the first time because
it isn't signed with their paid certificates yet.

This repository holds the downloads only.
